VHS

Your CLI home video recorder.

VHS lets you record terminal sessions to GIF and share with friends, colleagues, or the internet. It's like creating a video of your terminal, but simpler and more focused on the CLI experience.

Installation

go install github.com/charmbracelet/vhs@latest

Usage

Create a .tape file:

Output demo.gif
Set FontSize 32
Set Width 800
Set Height 400
Type "echo 'Hello, World!'"
Enter
Sleep 500ms

Then run VHS:

vhs < demo.tape
