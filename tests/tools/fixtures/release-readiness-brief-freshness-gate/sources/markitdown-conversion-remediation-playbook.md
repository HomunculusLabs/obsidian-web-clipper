# MarkItDown Conversion Remediation Playbook

## Summary
Step-by-step remediation procedures for common conversion issues.

## Remediation Procedures

### Code Block Issues
1. Check language hint syntax
2. Verify fence delimiter consistency
3. Test with minimal reproduction

### Table Issues
1. Validate column alignment markers
2. Check for malformed row separators
3. Test with simplified structure

### Image Issues
1. Verify relative path resolution
2. Check image format support
3. Test with absolute URLs
