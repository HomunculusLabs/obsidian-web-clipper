# Pilot User Selection (Batch of 3)

This file defines qualification rules for this outreach batch and records why each selected recipient qualifies.

## Fit Checklist (must meet all)
- [x] Uses Obsidian actively today for personal knowledge/work notes.
- [x] Clips web research frequently (target: 10+ pages/week).
- [x] Reports pain from manual cleanup, inconsistent structure, or weak metadata/frontmatter.
- [x] Can provide feedback within a 14-day pilot window.
- [x] Fits solo builder / technical founder profile from `OFFER_BRIEF.md`.

## Exclusion Criteria (exclude if any apply)
- [ ] Not currently using Obsidian (would confound onboarding vs product fit).
- [ ] Team/enterprise buyer expecting admin/compliance/SLA commitments.
- [ ] Requests custom integration or bespoke feature delivery as a condition to join.
- [ ] No recurring clipping workflow (occasional clipping only).
- [ ] Cannot commit to reply in the required CTA format (`PILOT YES - workflow - $/mo`).
